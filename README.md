# ✅ Task Manager

## ✨ Features

- ➕ Add tasks with a title and category
- ✅ Mark tasks as completed
- 🗑️ Delete individual tasks or clear all
- 🔍 Search tasks by title
- 🎛️ Filter by category and status
- 📊 Live stats — Total, Pending, Completed, Categories
- 🌙 Light / Dark mode toggle
- 📱 Fully responsive with mobile sidebar menu
- 💾 Theme preference saved in localStorage

## 🚀 How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/ankitsoni31/task-manager.git
   ```

2. Open the folder and double click `index.html`

That's it — no installation or build step needed!

---

## 📌 How to Use

1. Type a task title in the input field
2. Select a category (Study / Work / Personal / College)
3. Click **+ Add Task**
4. Use **Complete** to mark done, **Delete** to remove
5. Use the search bar and filters to find tasks
6. Toggle 🌙 / ☀️ for dark/light mode
